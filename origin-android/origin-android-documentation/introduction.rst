|vendor_name| Origin software development kit (SDK) allows developers to monetize, monitor, and
protect Android applications utilizing the |vendor_name| Origin Platform. Origin SDK is composed
of modules which may be integrated conditionally, depending on capabilities required by an
application.

Features
========

* Supports Android 4.4 (API level 19) and above.
* Supports mobile, smart TV, and other smart devices on which Android can be deployed.
* No dependencies outside of core Android APIs, :code:`androidx-core:core`, and
  :code:`com.google.guava:listenablefuture`.
* Extremely lightweight, with production AARs of a few hundred KB.
