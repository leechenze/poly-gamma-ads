***********
Development
***********

Origin is an open-source platform, developed by Poly-Gamma, providing distribution channel
monitoring, protection, and monetization. Origin Android SDK is a pure Java implementation for
interacting with the *header* module of the Origin Platform. The header platform module provides
distribution channel facing capabilities.
